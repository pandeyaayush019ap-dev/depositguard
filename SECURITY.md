# Security Policy

## Supported Versions

DepositGuard maintains security updates for the primary release line:

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within DepositGuard, please do not disclose it publicly. Contact the core maintainers directly or open a confidential security advisory on GitHub.

We investigate all reports promptly and aim to deploy patches within 48 hours for critical issues.
